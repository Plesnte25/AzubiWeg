# 🇩🇪 The German Alphabet

German uses the Latin alphabet just like English.

However, it also contains four additional letters.

There are

- 26 standard letters
- 3 umlauts
- 1 Eszett (ß)

Total

**30 letters/symbols**

# 📖 Chapter 6 — German Capitalization

One of the first things English speakers notice is that **German capitalizes all nouns**.

Unlike English, where only proper nouns are capitalized, German capitalizes **every noun**, whether it refers to a person, place, object, or concept.

---

## Rule 1 — Every Noun Begins with a Capital Letter

### Examples

| English | German |
|----------|---------|
| house | **Haus** |
| book | **Buch** |
| woman | **Frau** |
| man | **Mann** |
| student | **Student** |
| city | **Stadt** |

---

### Example Sentences

Ich habe ein **Buch**.

Sie wohnt in einer **Stadt**.

Das **Haus** ist groß.

Die **Familie** ist nett.

Der **Lehrer** spricht Deutsch.

---

## Rule 2 — Verbs Are NOT Capitalized

Correct

Ich **wohne** in Patna.

Incorrect

Ich **Wohne** in Patna.

---

## Rule 3 — Adjectives Are NOT Capitalized

Correct

Das Haus ist **groß**.

Incorrect

Das Haus ist **Groß**.

---

## Rule 4 — Nationalities Are Usually Lowercase

Correct

Ich bin **deutsch**.

Er ist **indisch**.

Sie ist **französisch**.

---

When nationality is used as a noun, it becomes capitalized.

Example

Der **Deutsche**

Die **Inderin**

Der **Franzose**

---

## Quick Summary

| Word Type | Capitalized? |
|------------|--------------|
| Nouns | ✅ Yes |
| Proper Names | ✅ Yes |
| Verbs | ❌ No |
| Adjectives | ❌ No |
| Nationalities (adjective) | ❌ No |
| Nationalities (noun) | ✅ Yes |

---

# 💡 Memory Tip

Think of German nouns as **important people**.

Every noun wears a **capital-letter hat**.

# 📖 Chapter 8 — Formal vs Informal

German has two ways to say **you**.

---

## Informal

**du**

Use when speaking with

- Friends
- Family
- Children
- Close classmates
- People your own age (depending on context)

Examples

Hallo!

Wie heißt du?

Wo wohnst du?

---

## Formal

**Sie**

Use when speaking with

- Teachers
- Professors
- Elderly people
- Government officials
- Shopkeepers (initially)
- Interviewers
- Customers
- Strangers in professional settings

Examples

Guten Tag.

Wie heißen Sie?

Wo wohnen Sie?

Freut mich.

---

# Comparison

| Informal | Formal |
|-----------|---------|
| Hallo | Guten Tag |
| Tschüss | Auf Wiedersehen |
| Wie heißt du? | Wie heißen Sie? |
| Wo wohnst du? | Wo wohnen Sie? |

---

# 🇩🇪 German Culture Tip

When in doubt,

use **Sie**.

Native speakers may invite you to switch to **du** by saying:

> **Wir können uns duzen.**

Meaning

"We can use 'du' with each other."

# 🟥 German Sentence Structure

German follows a relatively fixed word order.

The most important rule is:

> **The conjugated verb is almost always the second element in a statement.**

This is known as the **Verb-Second (V2) Rule**.

---

## Basic Pattern

```
Subject + Verb + Other Information
```

Examples

```
Ich bin Student.

Du kommst aus Indien.

Er wohnt in Berlin.

Sie lernt Deutsch.

Wir sprechen Deutsch.
```

Notice that the verb always appears in the **second position**.

---

# Position vs Word

Many beginners think the verb must be the **second word**.

That is **incorrect**.

German grammar says:

> **The verb must be in the second POSITION, not necessarily the second WORD.**

Example

```
Heute gehe ich zur Schule.
```

Here,

```
Heute
```

is Position 1.

```
gehe
```

is Position 2.

```
ich
```

comes after the verb.

---

## Example

❌ Incorrect

```
Heute ich gehe zur Schule.
```

✅ Correct

```
Heute gehe ich zur Schule.
```

---

# Common Sentence Patterns

---

## Pattern 1

Subject first

```
Ich lerne Deutsch.
```

---

## Pattern 2

Time first

```
Heute lerne ich Deutsch.
```

---

## Pattern 3

Place first

```
In Berlin wohne ich.
```

---

## Pattern 4

Object first

```

```

Again,

the verb remains second.
