>

- [ ] Learn 15 new vocabulary words.

- ö
- ü

- sch
- ei
- ie

# 🟦 Reading

## Reading Passage

Read the following aloud twice.

> Hallo!
>
> Ich heiße Anna.
>
> Ich komme aus Deutschland.
>
> Guten Tag!

### Tasks

- [ ] Read silently.
- [ ] Read aloud.
- [ ] Underline unfamiliar words.
- [ ] Read again with correct pronunciation.

### Comprehension

Answer in German if possible.

1. Wie heißt sie?
2. Woher kommt sie?
3. Welche Begrüßung benutzt sie?

### Deliverable

Write **two German sentences** summarizing the passage.

# 🟩 Speaking

## Shadowing (10 Minutes)

Repeat every greeting aloud after the speaker.

Examples:

- Hallo!
- Guten Morgen!
- Guten Tag!
- Auf Wiedersehen!

---

## Speaking Task

Practice saying:

- Hallo!
- Ich heiße ______.
- Ich komme aus ______.
- Ich lerne Deutsch.

Repeat each sentence **five times**.

---

## Conversation Practice

Pretend someone asks:

- Wie heißt du?
- Woher kommst du?

Answer naturally in German.

---

## Recording

- [ ] Record yourself.
- [ ] Listen to the recording.
- [ ] Repeat difficult words.

# 🟪 Writing

## Task

Write a short introduction (3–5 sentences).

Example structure:

- Ich lerne Deutsch.

**Do not copy—write your own version.**
