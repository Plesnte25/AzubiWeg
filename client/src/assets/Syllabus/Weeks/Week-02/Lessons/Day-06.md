# 🟥 Grammar

# Basic Adjectives

## What is an adjective?

An adjective describes a person, place, or thing.

Examples:

English:

> A big house.

German:

> Ein großes Haus.

---

## Common Beginner Adjectives

| German | English |
|---|---|
| groß | big |
| klein | small |
| schön | beautiful |
| alt | old |
| neu | new |
| gut | good |
| schlecht | bad |
| schnell | fast |
| langsam | slow |
| teuer | expensive |
| billig | cheap |
| einfach | easy |
| schwer | difficult |

---

# Adjective Position

In German, adjectives usually come before the noun.

Structure:

```

Article + Adjective + Noun

```

Examples:

---

## Der Tisch

The table

### A big table

> Der große Tisch.

---

## Die Tasche

The bag

### A new bag

> Die neue Tasche.

---

## Das Buch

The book

### A good book

> Das gute Buch.

---

# Beginner Rule

At A1 level, focus first on recognizing the pattern:

```

der + adjective + noun

die + adjective + noun

das + adjective + noun

```

Do not try to memorize every adjective ending immediately.

You will learn the full adjective declension system later.

---

# Sentence Examples

## Objects

> Das ist ein großes Haus.

This is a big house.

---

> Das ist ein kleines Buch.

This is a small book.

---

> Der Tisch ist alt.

The table is old.

---

> Die Tasche ist neu.

The bag is new.

---

> Das Handy ist teuer.

The phone is expensive.

---

# Describing Objects

Useful patterns:

## Pattern 1

```

Das ist + article + adjective + noun

```

Examples:

> Das ist ein rotes Buch.

This is a red book.

---

> Das ist eine schwarze Tasche.

This is a black bag.

---

## Pattern 2

```

Noun + sein + adjective

```

Examples:

> Das Buch ist interessant.

The book is interesting.

---

> Der Tisch ist groß.

The table is big.
