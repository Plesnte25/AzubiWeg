# 🎨 Color System

> This document defines the official visual language used throughout the **German B1 Roadmap**.

Every lesson, assignment, quiz, weekly schedule, examination, and progress tracker uses a consistent set of colors to help learners instantly identify the skill they are working on.

The same colors should be used across:

- Markdown Documentation
- Obsidian Vault
- AzubiWeg Learning Hub
- PDF Exports
- Flashcards
- Study Planner
- Progress Dashboard

---

# Design Philosophy

Each learning activity belongs to **one primary language skill**.

Instead of reading long headings, learners should recognize the skill immediately through color recognition.

Example

🟥 Grammar

↓

"I know I'm studying grammar."

# Accessibility

The roadmap is designed to remain understandable even without color.

Every section includes:

- Emoji
- Heading
- Consistent ordering
- Icons
- Labels

This ensures accessibility for learners with color vision deficiencies and improves readability in monochrome or printed formats.

---

# Guiding Principle

> Colors are not decoration—they are navigation.

A learner should be able to glance at a page and instantly understand which language skill is being practiced, how much progress has been made, and what remains to be completed.
