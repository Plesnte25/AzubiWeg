# 📚 Learning Resources

> This document defines the official learning resources used throughout the **German B1 Roadmap**.

## Guiding Principles

The roadmap follows these rules:

- One **primary** resource for structured learning.
- A small number of **supporting** resources.
- Avoid resource overload.
- Learn first, optimize later.
- Prefer free, high-quality content.

The curriculum is built around **consistency**, not collecting dozens of apps.

# Resources You Should NOT Depend On

- Random TikTok lessons
- AI-generated vocabulary lists without review
- Memorizing isolated word lists
- Multiple grammar books simultaneously
- Constantly switching between apps

---

# The 80/20 Study Stack

If you could only use five resources, use these:

1. ⭐ DW – Nicos Weg
2. ⭐ Obsidian Vocabulary Vault
3. ⭐ Lingolia
4. ⭐ Easy German
5. ⭐ Goethe Official Practice

These five resources cover nearly everything required to reach B1 when combined with consistent daily practice.

---

# Final Recommendation

> **Master a few excellent resources rather than browsing dozens of average ones.**

This roadmap intentionally limits the number of core tools. Repetition, structured progression, and daily practice are far more effective than continually searching for new resources.
